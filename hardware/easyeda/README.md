# EasyEDA PCB Design

This directory is reserved for the editable EasyEDA schematic/PCB project and visual design exports.

## Planned visual exports

- `renders/pcb-2d-routing.png` — 2D PCB routing/layout view.
- `renders/pcb-3d-perspective.png` — 3D perspective render.
- `renders/pcb-3d-top.png` — 3D top render.

The renders document the PCB design; they are not evidence that the PCB was fabricated or assembled.

## Recommended source and manufacturing files

When available, add the original EasyEDA project/source, a checked Gerber package, NC drill files, board outline, fabrication notes and a bill of materials. Run ERC/DRC and verify the outputs before manufacturing.
